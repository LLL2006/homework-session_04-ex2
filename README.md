# Dự án Quản lý Thông tin - SS4 B2

## Giới thiệu
Đây là dự án thực hành Quản lý nhánh và Giải quyết xung đột (Merge Conflict) trong Git.

## Mô tả phiên bản
Phiên bản đã giải quyết xung đột thành công: Kết hợp nội dung cập nhật từ cả nhánh chính `main` và nhánh tính năng `feature-update`.
- Nhánh `main`: Cập nhật cấu trúc và thông tin nền tảng.
- Nhánh `feature-update`: Bổ sung tính năng mới hoàn chỉnh.
